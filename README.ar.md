# MSF Skills · مصنع مصطفى للبرمجيات بالذكاء الاصطناعي

**من الفكرة إلى برمجيات مؤسسية احترافية.**

من إعداد مصطفى. تضم MSF Skills مهارات مستقلة باللغتين العربية والإنجليزية، ومراجع تنفيذ وفحوصًا وأمثلة لتسليم البرمجيات. اختر لغة وابدأ بالمنسّق، أو استدعِ المهارة المتخصصة مباشرة.

[English](README.md) · [التثبيت](INSTALL.ar.md) · [سجل المصادر والتراخيص](GITHUB_SOURCES.ar.md) · [أرشيف المصادر الخارجية](vendor/README.ar.md)

## استراتيجية وكلاء الذكاء الاصطناعي

تعمل [استراتيجية MSF لإدارة الوكلاء](skills/msf-ai-agent-strategy-ar/SKILL.md) مع المنسّق للمهام الطويلة: تحديد السياق المطلوب، تقسيم المهام، حفظ القرارات والحالة في ملفات المشروع، إنشاء نقاط استئناف، وتسليم العمل بين الجلسات مع أدلة الاختبارات. تقلل هذه الإجراءات تدهور السياق لكنها لا تضمن ذاكرة مثالية.

## البدء

ثبّت من نسخة راجعتها بالاستعانة بـ[دليل التثبيت](INSTALL.ar.md). عند بدء مهمة، استدعِ المنسّق وحدّد الهدف والمستودع ومعايير القبول وحدود العمل. يفحص المنسّق المشروع ويختار المسارات ذات الصلة ويرفق الأدلة، مع الالتزام بأعراف المستودع والتفويض.

```sh
python3 scripts/verify-environment.py
python3 scripts/run-quality-gates.py
python3 scripts/run-quality-gates.py --with-video
```

تعمل الفحوص المحلية دون اتصال. تعتمد التكاملات الاختيارية على بيئاتها وتبعياتها وتفويضها. يوضّح [دليل الجودة والإصدار](docs/ar/quality.md) الفرق بين أدلة الفحص المحلي والنشر. يسرد [تقرير التحقق](docs/ar/verification.md) الفحوص التي نُفّذت على النسخة المرشحة.
