# MSF Skills · مصنع مصطفى للبرمجيات بالذكاء الاصطناعي

**من الفكرة إلى برمجيات مؤسسية احترافية.**

من إعداد مصطفى. تضم MSF Skills مهارات مستقلة باللغتين العربية والإنجليزية، ومراجع تنفيذ وفحوصًا وأمثلة لتسليم البرمجيات. اختر لغة وابدأ بالمنسّق، أو استدعِ المهارة المتخصصة مباشرة.

[English](README.md) · [التثبيت](INSTALL.ar.md) · [سجل المصادر والتراخيص](GITHUB_SOURCES.ar.md)

## المجالات والمهارات والمصادر الخارجية

| العدد | المقصود |
| --- | --- |
| **9 مجالات عمل** | اكتشاف المتطلبات والتخطيط، المعمارية، تجربة المستخدم، التطوير المتكامل، الأمن، الاختبارات، DevOps، التوثيق، وإنتاج الفيديو |
| **12 مهارة أصلية من MSF** | منسّق واحد و11 مهارة متخصصة. ينقسم التطوير المتكامل إلى الواجهة الأمامية والخادم وقاعدة البيانات. |
| **24 مجلد مهارة قابلًا للتثبيت** | 12 نسخة عربية و12 نسخة إنجليزية. راجع [سجل المهارات](config/skill-registry.yaml). |
| **19 رابطًا خارجيًا في الطلب الأول** | مصدر للتخطيط، ومصدران لتجربة المستخدم، ومستودع مهارات Anthropic، وثلاثة مستودعات Playwright، و12 مصدرًا للفيديو. |
| **43 مصدرًا خارجيًا موثّقًا** | يشمل [سجل المصادر والتراخيص](GITHUB_SOURCES.ar.md) الروابط الأولى والمراجع التي أُضيفت لاحقًا. |

يختار المنسّق من المهارات الداخلية الـ11 حسب المهمة. تشمل المصادر الخارجية مهارات وإضافات ومكتبات وأدوات ووثائق. ثبّت التبعية الخارجية عندما يتطلبها المسار المختار. الرقم **31** يجمع المهارات الأصلية الـ12 والروابط الخارجية الـ19 في القائمة الأولى.

## دليل المهارات

لكل معرّف إنجليزي مهارة عربية مكافئة تنتهي بـ `-ar`. يضم سجل المهارات 24 مجلدًا قابلًا للتثبيت.

| المهارة | الاستخدام |
| --- | --- |
| `msf-orchestrator-ar` | فهم الهدف وفحص المستودع والتوجيه الانتقائي وإثبات النتائج |
| `msf-planning-ar` | المتطلبات والإجراءات والقصص والمهام والمخاطر والقرارات |
| `msf-architecture-ar` | الحدود والقرارات المعمارية وإعادة الهيكلة ومراجعة الكود |
| `msf-ui-ux-ar` | واجهات المؤسسات والاتجاهان والسمات والإتاحة والنقد البصري |
| `msf-frontend-ar` | Angular وTypeScript والنماذج والحالة والتكامل مع API |
| `msf-backend-ar` | ASP.NET Core وREST والمصادقة والوظائف وSignalR |
| `msf-database-ar` | SQL Server وEF Core والاستعلامات والسلامة والترحيل |
| `msf-security-ar` | المراجعة الدفاعية المصرّح بها وDevSecOps |
| `msf-testing-ar` | CRUD وAPI والمتصفح والإتاحة والانحدار |
| `msf-devops-ar` | CI/CD وIIS والحاويات والبنية والاعتمادية والإصدارات |
| `msf-documentation-ar` | الأدلة وOpenAPI والنشر والأعطال وملاحظات الإصدارات |
| `msf-video-studio-ar` | التقاط الواجهة والسرد والترجمة والتصيير وفحص الوسائط |

## البدء

ثبّت من نسخة راجعتها بالاستعانة بـ[دليل التثبيت](INSTALL.ar.md). عند بدء مهمة، استدعِ المنسّق وحدّد الهدف والمستودع ومعايير القبول وحدود العمل. يفحص المنسّق المشروع ويختار المسارات ذات الصلة ويرفق الأدلة، مع الالتزام بأعراف المستودع والتفويض.

```sh
python3 scripts/verify-environment.py
python3 scripts/run-quality-gates.py
python3 scripts/run-quality-gates.py --with-video
```

تعمل الفحوص المحلية دون اتصال. تعتمد التكاملات الاختيارية على بيئاتها وتبعياتها وتفويضها. يوضّح [دليل الجودة والإصدار](docs/ar/quality.md) الفرق بين أدلة الفحص المحلي والنشر. يسرد [تقرير التحقق](docs/ar/verification.md) الفحوص التي نُفّذت على النسخة المرشحة.
