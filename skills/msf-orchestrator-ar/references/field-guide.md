# التوجيه والأدلة

طابق المهارات مع المخرج والمخاطر. اجمع مسارات فقط عندما تعبر الميزة حدودها. استخدم البديل عند غياب المهارة. المهارات تعليمات، فحدّد الأدوات المحلية المتاحة قبل تشغيل الأوامر.

| الهدف | المهارة | البديل |
| --- | --- | --- |
| متطلبات غير واضحة أو مستودع قائم | `msf-planning-ar` | احصر الأطراف والمسارات والتبعيات ومعايير القبول. |
| حدود الخدمات أو إعادة الهيكلة | `msf-architecture-ar` | ارسم ملكية الكتابة والقواعد والعقود وأنماط الفشل قبل التغيير. |
| سهولة استخدام لوحة أو نموذج | `msf-ui-ux-ar` | افحص المهام الحقيقية والسمتين ولوحة المفاتيح والاتجاهات المعنية. |
| تنفيذ تطبيق متصفح | `msf-frontend-ar` | تتبّع المسار والحالة وعقد API والنموذج ودورة الطلب. |
| نقطة API أو وظيفة خلفية | `msf-backend-ar` | تحقّق من التفويض والتحقق وسلوك الخطأ وإعادة المحاولة. |
| تعديل مخطط أو استعلام أو بيانات | `msf-database-ar` | راجع القيود والتوافق وقِس على المحرك المستهدف. |
| حد ثقة أو مراجعة أمنية | `msf-security-ar` | استخدم نموذج تهديدات واختبارات دفاعية مصرّحًا بها. |
| انحدار أو قبول | `msf-testing-ar` | شغّل الفحوص المناسبة وسجّل النتائج الدقيقة والفجوات. |
| بنية أو نشر أو حادث | `msf-devops-ar` | أعد حدود الصحة والأدلة والتفويض وخطة التراجع. |
| دليل أو مرجع API أو سجل تغييرات | `msf-documentation-ar` | طابق الوثائق مع نقاط الدخول والمخرجات والإصدارات الفعلية. |
| فيديو تدريبي للبرنامج | `msf-video-studio-ar` | استخدم لوحة مشاهد ولقطات مصرّحًا بها وترجمة مقروءة ونتيجة فحص الوسائط. |

## أمثلة على القرارات

- اختر تجربة المستخدم والاختبارات لمعالجة خلل في السمة الداكنة. اقرأ تنفيذ الواجهة قبل التعديل وأضف مهارة الواجهة إذا احتجت تعديل مكوّن أو حالة.
- اختر الخادم لنقطة مخزون جديدة وأضف البيانات عند تغيير التخزين والأمن للصلاحيات والاختبارات. أضف المعمارية عند الحاجة لقرار في الحدود أو العقود.
- لدليل مبني على لقطات قدّم مهارة الفيديو أو التوثيق حسب المخرج المطلوب. يدخل الإصدار في النطاق عند طلب النشر.

سجّل لكل بوابة الحالة والأمر أو الأثر والنطاق والمراجعة والسبب. الفحص الذي شُغّل وفشل حالته FAIL. غياب التفويض أو التبعيات أو الأدلة حالته BLOCKED. ما يخرج عن النطاق حالته NOT APPLICABLE مع السبب. استخدم PASS مع دليل فعلي حديث.
