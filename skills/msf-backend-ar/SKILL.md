# msf-backend-ar

## النطاق

استخدمها لتطوير الخادم في ASP.NET Core .NET 10+ أو C# أو REST أو SignalR أو إطار مكافئ. احفظ سلوك العملاء والبيانات القائمة.

## المدخلات

حالات استخدام النقاط وسياسات التفويض والعقود والتخزين وأعطال التكامل واحتياجات التشغيل.

## المتطلبات

افحص SDK والإطار المستهدف وعملاء API والمسارات وإعداد اختبارات التكامل.

## خطوات العمل

1. حدّد حالات HTTP والأخطاء المنظمة وDTOs محددة الحقول وقواعد التحقق. أعد استخدام الخدمات وأعمار DI ومرّر الإلغاء واحفظ حدود المعاملات. اجعل التنفيذ مباشرًا حين تكون قواعد المجال بسيطة.
2. افرض المصادقة وصلاحية الكائن في الخادم وتحقّق من توقيع JWT والمُصدر والجمهور والمدة. اضبط المهلات وسلوك التكرار. فوّض عمليات Hub واضبط نطاق المجموعات واختبر إعادة الاتصال. استخدم سجلات منقّحة بمعرّف تتبع واضبط حدود عمل الخلفية وحدّث OpenAPI.

## السلامة

احمِ رؤوس التفويض والبيانات الشخصية من السجلات. استخدم مزود الأسرار وبيئات تكامل مصرّحًا بها. تجنّب إضعاف المصادقة وتعيين الحقول غير المصرح بها وتغيير العقود دون تنبيه.

## المخرجات

نقاط API أو وظائف، وعقد محدث، وملاحظات ترحيل أو توافق، واختبارات.

## التحقق

شغّل البناء والاختبارات. تحقّق من 400 و401 و403 و404 والتعارض وإعادة المحاولة والوصول إلى كائنات الغير حسب النطاق.

## معالجة التعثر

إذا توقف التكامل فاستخدم بديلًا مضبوطًا لاختبار العقد وسجّل التحقق الحي BLOCKED.
