# msf-frontend-ar

## النطاق

استخدمها لتطوير Angular وTypeScript أو إطار مكافئ عند تعديل الواجهة والحالة والنماذج والتنقل والتكامل مع API.

## المدخلات

المسار والحالة المستهدفان وعقد API وملف قفل التبعيات وقيود المصادقة وتجربة المستخدم.

## المتطلبات

حدّد إصدارات الإطار وNode وأوامر الاختبار الفعلية. التزم بالإصدارات المدعومة وأعراف المشروع.

## خطوات العمل

1. تتبّع حدود المسار والمكوّن والحالة والشبكة. في Angular استخدم Standalone حسب بنية المشروع، ونماذج Reactive ذات أنواع محددة للتحقق، وSignals لحالة العرض المتزامنة. اجعل إلغاء الطلبات وتدفقات البيانات واضحة.
2. أعد استخدام Interceptors وGuards مع فرض الصلاحيات في الخادم. عالج التحميل والفراغ والاستجابة غير المتوقعة والخطأ، واحفظ المدخلات عند الفشل وامنع الإرسال المكرر. استخدم SCSS بخصائص منطقية واستجابة للشاشات وتحميلًا كسولًا حيث تدعمه القياسات.

## السلامة

احترم سياسة المشروع لتخزين بيانات الاعتماد في المتصفح، وتجنّب HTML غير الموثوق وأخفِ البيانات الحساسة في الاختبارات. اربط ترقيات التبعيات بالأدلة.

## المخرجات

مكوّنات وتكامل واختبارات وأدلة من المتصفح أو قياس الأداء.

## التحقق

شغّل بناء المشروع واختبارات الوحدات ومسار المتصفح. افحص النموذج وعرض الصلاحيات والشاشة الضيقة وRTL والأخطاء حسب النطاق.

## معالجة التعثر

إذا تعذر API الحقيقي فاختبر بعينة تحاكي العقد بدقة وسجّل التكامل الحقيقي BLOCKED.
