# صيغة مخطط الفيديو ودليل الالتقاط

ضع المخطط بجوار ملفاته. يتضمن `title` (عنوانًا للتخطيط لا يظهر تلقائيًا في الفيديو)، و`locale` بقيمة `ar` أو `en`، و`asset_scope` بقيمة `synthetic` أو `approved_sanitized` بعد المراجعة، ومن مشهد واحد إلى 40 مشهدًا داخل `scenes`. احفظ سجلات الموافقة خارج ملف المخطط.

| الحقل | المعنى |
| --- | --- |
| `source` | صورة PNG أو JPG أو WebP، أو مقطع MP4 أو MOV أو MKV أو WebM تحت مجلد المخطط. تثبت الصورة طوال المشهد، ويثبت الإطار الأخير إن كان المقطع أقصر. تُضاف حواف عند اختلاف نسبة الأبعاد عن 16:9. |
| `duration` و`source_start` | مدة المشهد من 0.5 إلى 300 ثانية، مقرّبة إلى أقرب إطار، وموضع اختياري لبدء المقطع. يبدأ التعليق عند بداية المشهد بغض النظر عن موضع المقطع. |
| `transition` | يمكن تحديد `fade_in` و`fade_out` بالثواني حتى نصف مدة المشهد. التدرّج من الأسود وإليه لا يداخل زمن المشاهد؛ اتركهما محذوفين للقص المباشر. |
| `captions` | عناصر `{start,end,text}` مرتبة دون تداخل وبالثواني داخل المشهد. تُحوّل تلقائيًا إلى توقيت ملف SRT بترميز UTF-8. تُدمج الترجمة في الصورة افتراضيًا. |
| `overlays` | استخدم `start` و`end` لكل عنصر. للمؤشر `cursor` موضع `at: [x,y]` ووجهة اختيارية `to: [x,y]`؛ للإطار `focus` مستطيل `box: [x,y,width,height]`؛ وللعبارة `callout` مركز `at: [x,y]` ونص `text`. تستند الإحداثيات إلى مساحة 1920 × 1080 بما فيها الحواف. |
| `narration` للمشهد و`music` للفيديو | كائنان اختياريان بالشكل `{source,approval,gain}`. استخدم ملف WAV أو MP3 أو M4A أو FLAC أو OGG محليًا. اختر `provided_approved` أو `licensed_synthetic` للموافقة بعد التحقّق الفعلي. يُقص التعليق على طول المشهد ومستواه الافتراضي 0.85، وتتكرر الموسيقى بمستوى افتراضي 0.12 في الخلفية. |

أبرز عنصرًا مهمًا في كل خطوة، واكتب عبارات قصيرة واترك مساحة للترجمة. لدقة حقيقية في تفاصيل واجهة 4K، التقط الأصول بدقتها الأصلية. تُكبَّر مدخلات 1080p عند الإخراج بدقة 4K؛ ولا يضيف التكبير تفاصيل جديدة.

## التقاط محلي اختياري

شغّل بيئة التدريب المُجازة على عنوان محلي دون حساب أو جلسة مخزنة. ثبّت Playwright في بيئة Node.js محلية مع Chromium. شغّل برنامج الالتقاط بملف خطة ومجلد إخراج جديد:

```json
{
  "asset_scope": "synthetic",
  "locale": "ar",
  "url": "http://127.0.0.1:8765/fixture.html",
  "record_video": false,
  "steps": [
    {"wait_for":"#begin","file":"start.png"},
    {"click":"#begin","wait_for":"#success","hold_ms":500,"file":"finish.png"}
  ]
}
```

يمكن للخطوة الضغط على عنصر، أو اختيار قيمة مثل `"select": {"locator":"#status","value":"ready"}`، أو انتظار ظهور عنصر، أو التوقف حتى عشر ثوانٍ قبل حفظ PNG. اجعل `record_video` تساوي `true` لحفظ تسجيل WebM للمتصفح بدقة 1920 × 1080 أيضًا. يمنع السكربت الطلبات خارج أصل الموقع، وعاملي الخدمة، والتنزيلات، واتصالات WebSocket. لكن التسجيل يرى كل ما يظهر في الصفحة؛ نقّحها قبل الالتقاط وافحص المشاهد كلها. لتطبيقات سطح المكتب استخدم تسجيلًا مُعتمدًا ومُنقّحًا مسبقًا.

## أدوات خارجية اختيارية

بعد الحصول على إذن يشمل الخدمة والمادة، يمكن استيراد تعليق عام من [ElevenLabs](https://elevenlabs.io/docs/overview/intro)، أو مقطع مقدّم مرخّص من [HeyGen](https://developers.heygen.com/) أو [Synthesia](https://docs.synthesia.io/)، أو مونتاج من [Descript](https://help.descript.com/). صدّر الملف محليًا وافحصه قبل الاستيراد. إذا أردت الاحتفاظ بكلام المقدم، صدّر مسار الصوت على حدة وأضفه بوصفه تعليقًا مُجازًا. الاستيراد يدوي، ولا يتضمن مفاتيح API أو وصلات مدمجة أو إرسالًا تلقائيًا. عند غموض شروط الاستخدام أو الموافقات أو التعامل مع البيانات، استمر بالمسار المحلي.

### أدوات اختيارية للتأليف والترجمة

- [Remotion](https://github.com/remotion-dev/remotion) و[HyperFrames](https://github.com/heygen-com/hyperframes): خياران عندما يحتاج المشروع قوالب حركة خاصة مبنية على HTML أو React. راجع الترخيص والمتطلبات أولًا، ثم صدّر المقطع إلى ملف فيديو محلي؛ لا تأتي الأداتان ضمن الحزمة.
  لمسار Remotion راجع [دليل MSF الاختياري ومثال اللغتين](remotion.md)؛ تظل الحزم الخارجية اختيارية.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper): يمكن استخدام نموذج محلي مُجاز لإعداد مسودة للترجمة والتوقيت. يراجع متحدث متمكن المصطلحات وترتيب القراءة والتزامن قبل نقلها إلى المخطط. لا تجلب أداة الإخراج أي نموذج تلقائيًا.
- [edge-tts](https://github.com/rany2/edge-tts): خيار صوتي عبر الإنترنت للنصوص والأصوات المُجازة. راجع شروط الخدمة وإمكانية الوصول قبل إنشاء مسار محلي. لا تستدعيه أداة الإخراج.
- يميّز سجل المصادر بين [onetake لصناعة المقاطع المتحركة](https://github.com/feitangyuan/onetake)، و[onetake-videogen](https://github.com/Nael-Nathanael/onetake-videogen)، و[محرّر OneTake الآلي](https://github.com/leejersey/OneTake). افحص ترخيص المشروع المقصود وواجهاته قبل استخدام أي تصدير منه.
