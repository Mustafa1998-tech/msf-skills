# المسار الاختياري لإنشاء الفيديو باستخدام Remotion

[English](../../msf-video-studio/references/remotion.md) · [المثال التدريبي الجاهز](../../../examples/remotion-training-video/README.ar.md)

## متى نختاره؟

اختر **Remotion + React** إذا احتاج المشروع مقدمات متحركة أو مشاهد وعناصر وهوية بصرية مخصصة وانتقالات مبرمجة ونسخًا بلغات مختلفة. واستمر في مسار **FFmpeg** الحالي إذا كان المطلوب فيديو شرح للشاشات بإخراج محلي بسيط. يُستخدم Playwright اختيارياً لالتقاط واجهة مصرح بها. لا تصبح Remotion تبعية مفروضة على باقي مهارات MSF.

## التجهيز وخطوات الوكيل

1. تحقق من Node.js وnpm والاتصال إن لزم، ومن أهلية الجهة وفق [ترخيص Remotion الحالي](https://www.remotion.dev/docs/license/pricing). لا يحوّل ترخيص MSF ترخيص Remotion أو مهارات الوكيل الخارجية. استخدم إصدارات تابعة تمت مراجعتها واحفظ ملف قفل الحزم في مشاريع الإنتاج.
2. ابدأ من [المثال الأصلي ببيانات وهمية](../../../examples/remotion-training-video/README.ar.md)، أو أنشئ مشروع Remotion منفصلًا. من داخل مجلد المثال شغّل `npm install` ثم `npm run typecheck` ثم `npm run dev`.
3. إذا احتاج الوكيل تعليمات Remotion الرسمية، وبعد مراجعتها، شغّل `npx remotion skills add` **داخل مشروع Remotion**. يحتفظ مستودع MSF بمراجع المهارات الرسمية، وبأرشيف مُراجع لملحق Codex المرخص MIT في `vendor/` للفحص، ولا يفعّل أو يثبت أي مصدر خارجي تلقائيًا.
4. حدّد هدف التدريب وتسلسل المشاهد والنتيجة النهائية. استخدم مشاهد بدقة 1920 × 1080 و30 إطارًا في الثانية، وفصل النصوص العربية RTL عن الإنجليزية LTR. اجعل الحركة مرتبطة بالإطارات بشكل قابل للتكرار، دون بيانات مستخدمين حقيقية أو اعتماد على خدمة خارجية.
5. لتصدير المثال شغّل `npm run render:ar` و`npm run render:en` أو نسختيهما `:4k`. يستخدم خيار 4K العلم `--scale=2` وينتج 3840 × 2160. راجع الزمن ومعرّفات المشاهد ومحتوى الفيديو، ولا تُصنّف لقطة منخفضة الدقة على أنها تفاصيل 4K أصلية.

## التكامل مع MSF Video Studio

- **الالتقاط:** استخدم أداة Playwright في MSF على واجهة وهمية محلية، أو صورًا ومقاطع معتمدة ومنقحة. لا تُصوّر جلسات إنتاج حقيقية دون موافقة مناسبة.
- **الحركة:** أنشئ مقطع Remotion وصدّره إلى MP4 محلي. ملف React نفسه ليس مصدرًا تقبله أداة FFmpeg؛ المطلوب هو الفيديو الناتج.
- **التجميع الاختياري:** ضع الفيديو المعتمد أسفل مجلد المخطط، واجعله قيمة `source` في المشهد وحدد `duration` المناسبة. يستبعد مُصيّر MSF الصوت الأصلي للمقطع؛ أضف الصوت المعتمد منفصلًا. أبق الترجمة في مخطط MSF أو تجنب ازدواج ترجمتين ظاهرتين.
- **التسليم:** يُصدر مسار FFmpeg المعتاد MP4 وSRT وتقرير QA. أما مثال Remotion المستقل فيصدر MP4 فقط. اختبر الناتج بـ`ffprobe` وفك الترميز ومشاهدته بالسرعة العادية، ولا تدّعِ نجاح الإخراج أو وجود ترجمة وصوت دون إثبات.

## الأمان والجودة والتراخيص

استخدم بيانات وهمية أو لقطات منقحة ومصرحًا بها، ولا تنشر كلمات مرور أو بيانات شخصية أو عناوين داخلية أو أصواتًا تعريفية دون إذن. افحص اتجاه العربية وتشكيل الأحرف ومواضع المؤشر والتباين والتوقيت وظهور نجاح العملية. افحص ترخيص الاستخدام المؤسسي والتجاري أو الإنتاج الآلي قبل التنفيذ. عند غياب الاعتماديات أو فشل التصدير، سجّل الحالة BLOCKED واستخدم مسار FFmpeg المحلي؛ نجاح فحص TypeScript لا يعني إنتاج فيديو مجرّبًا.
