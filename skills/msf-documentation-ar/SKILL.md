# msf-documentation-ar

## النطاق

استخدمها لكتابة README وأدلة المستخدم والإدارة وOpenAPI وتوثيق المعمارية والتثبيت والنشر والأعطال وسجل التغييرات والإصدار.

## المدخلات

الجمهور والبناء أو الواجهة الحالية والمستودع ومخطط API واللغات وبيئة النشر.

## المتطلبات

افحص الأوامر الفعلية ونقاط الدخول واستجابات الأخطاء وإصدارات الآثار. استخدم لقطات آمنة أو أمثلة اصطناعية.

## خطوات العمل

1. رتّب حسب مهمة القارئ. وثّق المتطلبات والبدء السريع والتحقق والتحديث والإزالة أو التراجع وحل الأعطال بأعراض قابلة للرصد. اشرح المعاملات والنتائج والأدوار.
2. طابق OpenAPI مع المسارات والأمثلة الفعلية. افصل إجراءات النشر والإدارة عن خطوات المستخدم اليومية. طابق الأقسام العربية والإنجليزية وحافظ على المعرّفات والأوامر. اربط ملاحظات الإصدار بالتغييرات المثبتة.

## السلامة

نقّح معلومات الحسابات والأسرار. اربط ادعاءات الترخيص بالأدلة وميّز الميزات المخطط لها والفحوص التي تعتمد على البيئة.

## المخرجات

وثائق ثنائية اللغة وأوامر قابلة للتشغيل وروابط تراخيص ومصادر وسجل تغييرات وملاحظات إصدار.

## التحقق

شغّل الأوامر متى أمكن وافحص الروابط المحلية والتكافؤ اللغوي وطابق الادعاءات مع نتائج التنفيذ. اعرض حالة التنفيذ بدليل.

## معالجة التعثر

إذا غابت الأداة أو التطبيق فصرّح بأن الإجراء غير متحقق عمليًا وسجّل خطوة التحقق المحددة.
