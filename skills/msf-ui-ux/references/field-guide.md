# Field procedure

Review one task from entry to feedback. Record reference, what it solves, and the product-specific adjustment. Compare with [Impeccable](https://github.com/pbakaus/impeccable), [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [Anthropic Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) and [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) as distinct references. Critique in order: blocker to task completion, accessibility, hierarchy/consistency, responsive details, and polish. For each issue record viewport, locale, theme, reproduction, impact and correction. Test one-hand mobile use and desktop keyboard. For Tajawal or IBM Plex Sans Arabic check upstream license and distribution first. Avoid emoji as product icons.
