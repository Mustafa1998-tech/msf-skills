## Journey
Entry → action → validation → success/failure → next step.

## Required states
Populated, empty, loading, error, validation, disabled, confirm, permission denied and success where applicable.

## Acceptance checklist
- [ ] No unapproved sections removed, added or moved.
- [ ] Primary action and reading order are clear.
- [ ] Arabic labels and Latin identifiers display correctly.
- [ ] Responsive layout has no page-level overflow.
- [ ] Keyboard focus, labels and contrast checked.
- [ ] Screenshots and interaction tests are recorded.
- [ ] Unverified or blocked checks are declared.

## Handoff
Files changed, screenshot paths, test commands, findings by severity, limitations and recommended next step.
