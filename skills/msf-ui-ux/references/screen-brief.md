## Journey
Entry → action → validation → success/failure → next step.

## Required states
Populated, empty, loading, error, validation, disabled, confirm, permission denied and success where applicable.

## Acceptance checklist
- [ ] Visual identity was justified by actual product context (not a fixed MSF template).
- [ ] No unapproved sections removed, added or moved.
- [ ] Primary action and reading order are clear.
- [ ] Locale-specific layout and mixed-direction identifiers display correctly.
- [ ] Relevant responsive widths work without page-level overflow.
- [ ] Keyboard focus, labels and contrast checked.
- [ ] Actual screenshots and interaction tests are recorded, or marked BLOCKED.
- [ ] Unverified or blocked checks are declared.

## Handoff
Identity reasoning, files changed, screenshot paths, test commands, findings by severity, limitations and recommended next step.
