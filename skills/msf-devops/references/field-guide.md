# Field procedure

Promote the same artifact from staging and store digest, commit and workflow run ID. Separate readiness from liveness and define what a failed deployment means before rollout. Check backward compatibility before rolling back app code over a migrated database. For incidents record time zone, severity, timeline, measured recovery and follow-up owners. Use [Kubernetes](https://kubernetes.io/docs/) and [Terraform](https://developer.hashicorp.com/terraform/docs) docs for runtime-specific commands.
