# استراتيجية MSF لوكلاء الذكاء الاصطناعي

تعمل مع msf-orchestrator وجميع المهارات المتخصصة لتقليل تدهور السياق (Context Rot)، دون ضمان منع النسيان بالكامل.

## دورة العمل
1. افهم المتطلبات وتعليمات المستودع والقيود ومعايير القبول قبل البرمجة.
2. قسّم المشروع إلى مهام محدودة مع الاعتماديات والمخاطر ومعايير التحقق.
3. حمّل سياق المهمة الحالية فقط، واسترجع الملفات الأخرى عند الحاجة.
4. نفّذ على دفعات صغيرة وسجّل القرارات والعوائق.
5. تحقق بالبناء والاختبارات والفحوص الأمنية واختبارات المتصفح حسب المهمة.
6. احفظ حالة المشروع قبل ضغط السياق أو الانقطاع أو تسليم العمل لوكيل آخر.
7. عند الاستئناف، اقرأ الحالة وطابقها مع ملفات المستودع الحالية.

## قواعد منع تدهور السياق
- المحادثة ذاكرة عمل وليست المصدر الوحيد للحقيقة.
- راقب نسيان القيود والتناقضات وتكرار الأخطاء؛ لا يوجد حد توكنات يضمن الجودة.
- احتفظ بالمتطلبات والقرارات ومسارات الملفات ونتائج الاختبارات والمخاطر والخطوة التالية عند التلخيص.
- ابدأ جلسة جديدة بتسليم منظم إذا أصبح السياق مشوشًا.
- لا تخترع نتائج اختبارات، ولا تُسقط مهامًا معلقة، ولا تحفظ أسرارًا في ملفات المشروع.

## ملفات الحالة
استخدم ملفات المشروع الحالية إن وجدت، وإلا فأنشئ:
- PROJECT_STATE.md: الهدف والمرحلة والحالة المؤكدة والعوائق.
- DECISIONS.md: القرارات وتواريخها وأسبابها.
- TASKS.md: المهام والأولويات ومعايير القبول وأدلة التحقق.
- HANDOFF.md: العمل المنجز والملفات المعدلة ونتائج الأوامر والمخاطر والخطوة التالية.

## تعدد الوكلاء
فوّض مهامًا محددة بمعايير قبول واضحة. المنسق مسؤول عن الدمج والتحقق النهائي. تجنب تعديل الملفات نفسها بالتوازي دون تنسيق.

## بوابة الإكمال
لا تعلن اكتمال عمل لم يُسلّم أو يُتحقق منه. وضّح الفحوص غير المنفذة. لا تنشر أو تدمج أو تعدّل الإنتاج دون تصريح.
