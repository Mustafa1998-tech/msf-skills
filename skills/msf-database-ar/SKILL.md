# msf-database-ar

## النطاق

استخدمها مع SQL Server وT-SQL وEF Core والمخطط والإجراءات المخزنة والفهارس وتحسين الاستعلام والترحيل. تحقّق بمحرك قاعدة البيانات نفسه متى أمكن.

## المدخلات

المخطط والاستعلامات المهمة وحجم الحمل وقواعد سلامة البيانات والبيئة المصرّح بها.

## المتطلبات

افحص تاريخ الترحيل والمحرك وإصداره وإعداد المزود وبيانات الاختبار.

## خطوات العمل

1. حدّد المفاتيح والتكامل المرجعي والتفرّد وقابلية الفراغ. اربط سياسة المعاملات والتزامن بقواعد البيانات. افحص خطط التنفيذ الفعلية في بيئة آمنة وقارن القراءات والزمن وسجّل كلفة الفهرس عند الكتابة.
2. استخدم معاملات إدخال منفصلة عن نص الاستعلام والإجراءات. عالج الصفوف القديمة واتّبع التوسعة والتعبئة والتحقق ثم الإزالة عند الحاجة للتوافق. اختبر الدفعات وإعادة المحاولة والتزاحم والاستعادة. وثّق النسخ الاحتياطي والتعافي مع تجربة استعادة.

## السلامة

اطلب تفويضًا قبل الكتابة الحية أو حذف البيانات أو نشر تعديل مخطط. استخدم أقل صلاحية ونقّح البيانات والخطط قبل مشاركتها.

## المخرجات

ترحيل أو استعلام أو إجراء وخطة وقياسات وفحوص للبيانات وخطوات تراجع أو استعادة.

## التحقق

جرّب الترحيل على بيانات قديمة اصطناعية وافحص القيود والتزامن وإعادة المحاولة والتراجع عند توفره. استند إلى نتائج SQL Server عند الادعاء بسلوك خاص بالمحرك.

## معالجة التعثر

إذا تعذر المحرك نفّذ الفحوص المتاحة وسجّل التنفيذ على SQL Server بالحالة BLOCKED.
