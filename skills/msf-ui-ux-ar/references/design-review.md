# MSF — مراجعة تصميم قائمة على الأدلة

## مستويات الشدة

| المستوى | التعريف | الإجراء |
| --- | --- | --- |
| P0 | توقف المهمة الأساسية أو إجراء خطير مضلل | إيقاف القبول |
| P1 | خلل كبير في الإتاحة أو التحقق أو الجوال | إصلاح قبل النشر |
| P2 | خلل مهم في الهرمية أو المسافات أو الرسائل | إصلاح بالجولة التالية |
| P3 | عدم اتساق جمالي صغير | صقل بعد إكمال المسارات |

لكل مشكلة سجّل الشاشة والعرض والاتجاه والسمة وخطوات التكرار والنتيجة الحالية والمتوقعة والأثر والأولوية والإصلاح والدليل.

## عشرة معايير للنقد

قيّم كل معيار من 0 إلى 4: صفر غير قابل للاستخدام أو غير مفحوص، 1 خلل كبير، 2 تفاوت، 3 جيد مع فجوات، 4 قوي ومتحقق.

1. المهمة الأساسية والهرمية
2. التنقل وفهم موضع المستخدم
3. الإيقاع البصري والمساحات والتجميع
4. الخط واللغة والاتجاه المناسب للنظام والنصوص المختلطة
5. رموز التصميم والأيقونات والاتساق
6. التحميل والفراغ والخطأ والنجاح ورسائل الحالة
7. النماذج والجداول ووضوح التفاعل
8. الجوال واللوحي والمكتب
9. لوحة المفاتيح والتركيز والدلالات والتباين
10. ملاءمة الهوية وتميزها والمحاذاة والكثافة والصقل

درجة 34 من 40 على الأقل بلا P0 أو P1 غير محلولة هي **مؤشر قبول داخلي** وليست إثباتًا للإتاحة أو سهولة الاستخدام. اذكر المعايير غير المفحوصة ولا تمنحها درجة دون دليل.

## مصفوفة الأدلة

صوّر المسار الرئيسي على المكتب (1440 بكسل) واللوحي (768) والجوال (390) أو أبعاد المنتج المعتمدة. استخدم نفس البيانات والسمة والأبعاد والتكبير للمقارنة قبل وبعد. افحص اللغة والاتجاه المناسبين للنظام والنصوص الطويلة والأكواد المختلطة والتركيز وترتيب لوحة المفاتيح والجداول والبحث والنماذج. افحص التحميل والفراغ والتحقق والفشل. اختبر السمة الداكنة والحركة المخفضة حيث تنطبق. راجع ملاءمة الهوية البصرية للنظام بدل افتراض قالب موحد باسم MSF.

## التسليم

أرفق مواصفات الشاشة والملفات المنفذة واللقطات الفعلية والملاحظات P0–P3 والاختبارات المنفذة والقيود والنتيجة. عند غياب المتصفح سجّل فحصه BLOCKED. وضّح أن البيانات اصطناعية وأن النموذج بلا Backend عند انطباق ذلك.
