# نموذج مواصفات شاشة MSF

- اسم النظام / الشاشة:
- هدف النظام المؤكد والافتراضات المستنتجة من اسمه:
- نوع التغيير: جديدة / تحسين بصري فقط / إعادة تصميم مصرح بها
- المستخدمون الفعليون والصلاحيات:
- المهمة الرئيسية ومعايير النجاح:
- صور الشاشات والشعار ونظام التصميم والكود الحالي:
- شخصية الهوية والقيود البصرية الموجودة:
- الأقسام والإجراءات المطلوب الحفاظ عليها:
- اللغة / الاتجاه: RTL أو LTR أو متعدد اللغات حسب المنتج
- السمات والأجهزة المستهدفة التي يحتاجها المنتج:
- الأصول المرخصة ومصادر الإلهام:
- الاتجاهات المرشحة والاتجاه المختار وسبب اختياره:
- ما يميز هذا النظام بصريًا عن نظام في مجال آخر:

## رحلة المستخدم
الدخول ← الإجراء ← التحقق ← النجاح أو الفشل ← الخطوة التالية.

## حالات الواجهة
البيانات والفراغ والتحميل والخطأ والتحقق والتعطيل والتأكيد والصلاحيات والنجاح حسب الحاجة.

## قائمة قبول
- [ ] الهوية مبنية على سياق النظام وليست قالب MSF ثابتًا.
- [ ] لا إضافة أو حذف أو نقل لأقسام دون تفويض.
- [ ] الإجراء الأساسي وتسلسل القراءة واضحان.
- [ ] اللغة والاتجاه والأكواد المختلطة مناسبة للمنتج.
- [ ] الأبعاد ذات الصلة تعمل بلا تمرير أفقي غير مقصود.
- [ ] فُحصت لوحة المفاتيح والتركيز والتسميات والتباين.
- [ ] وُثقت الصور واختبارات التفاعل الفعلية أو سُجل تعذّرها.
- [ ] أُعلنت الفحوص غير المتحققة أو المتعذرة.

## التسليم
تبرير الهوية والملفات المعدلة وروابط الصور وأوامر الاختبار وملاحظات الشدة والقيود والخطوة التالية.
