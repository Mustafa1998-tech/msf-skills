# نموذج مواصفات شاشة MSF

- النظام / اسم الشاشة:
- نوع التغيير: جديدة / تحسين بصري فقط / إعادة تصميم مصرح بها
- المستخدمون والصلاحيات:
- المهمة الرئيسية ومعايير النجاح:
- صور وملفات الكود الحالية:
- الأقسام والإجراءات المطلوب الحفاظ عليها:
- اللغة / الاتجاه: عربي فقط RTL أو غير ذلك
- السمات والأجهزة المستهدفة:
- الهوية والأصول المرخّصة:

## رحلة المستخدم
الدخول ← الإجراء ← التحقق ← النجاح أو الفشل ← الخطوة التالية.

## حالات الواجهة
بيانات موجودة وفراغ وتحميل وخطأ وتحقق وتعطيل وتأكيد وصلاحيات ونجاح حسب الحاجة.

## قائمة قبول
- [ ] لا إضافة أو حذف أو نقل لأقسام دون تفويض.
- [ ] الإجراء الأساسي وتسلسل القراءة واضحان.
- [ ] العربية والأكواد اللاتينية تعرض بصورة صحيحة.
- [ ] الاستجابة بلا تمرير أفقي للصفحة.
- [ ] فُحصت لوحة المفاتيح والتركيز والتسميات والتباين.
- [ ] وُثقت الصور واختبارات التفاعل.
- [ ] أُعلنت الفحوص غير المتحققة أو المتعذرة.

## التسليم
الملفات المعدلة وروابط الصور وأوامر الاختبار وملاحظات الشدة والقيود والخطوة التالية.
