# msf-ui-ux-ar

## النطاق

صمّم أو نفّذ أو حسّن شاشات مؤسسية بمراجعة قائمة على الأدلة. قدّم سهولة إكمال المهام على الزينة، وحافظ على الأقسام والإجراءات الحالية عندما يكون المطلوب تحسينًا بصريًا فقط.

## المدخلات

هوية المنتج ومستودع الكود أو الصور والمستخدمون والمسارات والأقسام الدقيقة واللغة والأجهزة والسمات ومعايير القبول. حدّد هل يُسمح بتغيير بنية الشاشة أم تحسين مظهرها فقط.

## المتطلبات

افحص الواجهة ورموز التصميم الحالية. اقرأ معيار مراجعة التصميم ونموذج مواصفات الشاشة المرفقين. استخدم بيانات اصطناعية للنماذج المستقلة، وافحص التراخيص قبل إضافة أصول خارجية.

## خطوات العمل

1. **اكتشف واحفظ:** احصر الشاشات والتنقل والحقول والأقسام والإجراءات. لا تضف أو تحذف عناصر أو تعيد ترتيب المعلومات بصمت عند طلب تحسين الشكل فقط.
2. **حدّد المسارات:** عرّف المهمة والمستخدم ونقطة الدخول والنتيجة والتحقق والأخطاء والصلاحيات؛ ثم املأ مواصفات الشاشة.
3. **أنشئ نظامًا متسقًا:** عرّف الألوان الدلالية للفاتح والداكن والخطوط والمسافات والرموز والهرمية وحالات التركيز والرسائل. فضّل المظهر المتوازن والمؤثرات المحدودة والأيقونات غير التعبيرية.
4. **نفّذ حالات فعلية:** البحث والتصفية والجداول والفرز والفراغ والتحميل والخطأ والحقول الإلزامية والتأكيد والنجاح والتعطيل والصلاحيات عند الحاجة. استخدم HTML دلاليًا وتفاعلات تعمل بلوحة المفاتيح.
5. **احترم العربية والأجهزة:** استخدم RTL وخصائص CSS المنطقية وعزل اتجاه الأكواد اللاتينية والتسميات العربية الطويلة وأهداف اللمس وتمرير الجداول. لا تضف واجهة إنجليزية لنظام عربي فقط.
6. **انقد المظهر بالأدلة:** راجع صورًا فعلية وفق معيار الشدة، وقارن قبل وبعد بنفس العرض والبيانات والتكبير؛ وسجّل المشكلة والخطوات والأثر والإصلاح.
7. **حسّن وتحقق:** أصلح المشكلات المانعة أولًا ثم التفاصيل، واختبر المهام الأساسية في المتصفح وأرفق الصور وسجل الفحوص. ميّز النجاح المتحقق من الافتراضات.

## السلامة

استخدم محتوى مرخصًا واحمِ بيانات المستخدمين والأسرار في اللقطات. احترم الموافقات على الحذف والأنظمة الحية والإنتاج. لا تشغّل كودًا خارجيًا مؤرشفًا دون مراجعة وموافقة.

## المخرجات

واجهة تفاعلية أو تنفيذ فعلي ورموز تصميم ونموذج مواصفات ونقد مرتب بالأولوية وأدلة قبل وبعد وحالات استجابة وتفاعل وقيود باقية.

## التحقق

افحص 1440 و768 و390 بكسل أو الأبعاد المعتمدة والاتجاه المختلط والتركيز بلوحة المفاتيح والرسائل والسمات المعنية. افحص تباين WCAG 2.2 AA المناسب (4.5:1 للعادي و3:1 للكبير) والحركة المخفضة والتمرير. سجّل ما لم يُختبر BLOCKED لا PASS. درجة النقد ليست شهادة إتاحة.

## معالجة التعثر

عند تعذّر الوصول إلى التطبيق أو المتصفح أو الأصول أو الصلاحيات، قدّم نموذجًا مستقلًا مشروحًا وسجّل الفحص المتعذّر BLOCKED. لا تخترع لقطات أو نتائج.
