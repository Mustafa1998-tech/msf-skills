# msf-ui-ux-ar

## النطاق

استخدمها لتصميم أو نقد واجهات المؤسسات ولوحات المعلومات والنماذج والجداول وأنظمة التصميم والاتجاهين والسمات. طبّقها على مسارات المستخدم.

## المدخلات

هوية المنتج والجمهور والمهام الأساسية ولقطات أو واجهة قائمة واللغة والأجهزة المستهدفة.

## المتطلبات

اقرأ رموز التصميم والمكوّنات القائمة. استخدم واجهة حقيقية أو نموذجًا ببيانات اصطناعية ومراجع مرخّصة.

## خطوات العمل

1. حدّد المهمة الرئيسية والتنقل. قارن الأنماط المرجعية بهوية المنتج وسجّل القرارات، ثم عرّف رموز الألوان والدلالات والخط والمسافات والمكوّنات والحالات لكل سمة. استخدم أيقونات SVG مرخّصة أو أصلية.
2. نفّذ مسارًا ممثلًا وافحصه. استخدم خصائص CSS المنطقية وlang وdir وعزل النص المختلط وخطًا عربيًا مقروءًا. ميّز الإلزامي والاختياري، وأضف أخطاء واضحة واستعادة للتركيز وقوائم بحث وأشجارًا قابلة للوحة المفاتيح عند الحاجة. جهّز فرز الجداول وبحثها وتصفيتها وترقيمها وحالاتها.

## السلامة

استخدم أصولًا مرخّصة واحمِ اللقطات وبيانات المستخدمين. طبّق نظام تصميم المنتج واستخدم Impeccable Critique أو معيار النقد المرفق لتوثيق المشكلات بالأدلة.

## المخرجات

رموز تصميم وواجهة مستجيبة أو نموذج، ونقد مصنّف بالشدة، وفحوص قبول ولقطات أساس.

## التحقق

اختبر ترتيب لوحة المفاتيح والتركيز والتباين والعرض الضيق والنص العربي الطويل وكل زوج من اللغة والسمة والحركة المخفضة ورسائل الحالة. التقط صورًا قابلة للمقارنة عندما تتوفر الأدوات.

## معالجة التعثر

إذا غابت أداة النقد أو الخط فاستخدم المعيار المرفق وخطوطًا محلية بديلة، وسجّل فحوص المتصفح المتعذرة BLOCKED.
