# Field procedure

Draw browser, API, persistence and external services as separate trust zones. Verify authorization on every object read or mutation. Start static review with [CodeQL](https://github.com/github/codeql), dependency and image checks with [Trivy](https://github.com/aquasecurity/trivy), and approved passive DAST with [OWASP ZAP](https://github.com/zaproxy/zaproxy) when permitted by local policy. Verify licenses, exact version, permissions and safe mode before use. Avoid broad permissions for CI and preserve redacted evidence.
