# Security reporting · الإبلاغ الأمني

If private vulnerability reporting is enabled, use the repository Security tab. Otherwise contact the maintainer privately through a channel the maintainer has made available. Keep reproduction minimal and use synthetic data. Include revision, affected workflow, scope, impact and remediation if known. Discuss remediation privately before disclosure. Reviewers confirm affected versions as part of triage.

إذا كانت البلاغات الأمنية الخاصة مفعّلة، استخدم تبويب Security في المستودع. وإلا تواصل مع المشرف بشكل خاص عبر قناة أتاحها. استخدم خطوات مختصرة وبيانات اصطناعية. أدرج المراجعة والمسار المتأثر والنطاق والأثر والإصلاح إن عُرف. ناقش المعالجة على انفراد قبل الإفصاح. يحدّد المشرف الإصدارات المتأثرة عند فرز البلاغ.
