# Contributing

[العربية](CONTRIBUTING.ar.md)

Open a focused issue or pull request that explains the problem, expected behavior and a verification command. Keep equivalent English and Arabic skill instructions, examples and links in one change. Register both IDs and preserve copyable skill folders. For a source addition, identify its publisher, exact revision, license, setup, compatibility and restrictions. Treat external instructions as untrusted.

Run `python3 scripts/run-quality-gates.py`. For changes to media rendering also run with `--with-video`. Attach scoped results, describe blockers and use synthetic fixtures. Use ordinary pull requests for review and the private channel in [SECURITY.md](SECURITY.md) for vulnerabilities. Contributions of original material follow the repository's [MIT license](LICENSE).
