# التحقق من النسخة المرشحة الأولى

[English](../en/verification.md)

| النطاق | الدليل | النتيجة |
| --- | --- | --- |
| المستودع | `python3 scripts/run-quality-gates.py --with-video` | اجتازت النسخة ثماني بوابات محلية. يحتاج الإصدار البعيد دليلًا مستقلًا. |
| المهارات والتثبيت | `python3 scripts/validate-skills.py` واختبارات دورة التثبيت | تحقّق تنسيق 24 مجلدًا. نُسخت المهارات كلها إلى مشروع Codex مؤقت وأُزيلت كل لغة على حدة. جُرّب مسار Claude Code للمستخدم في مجلد منزلي معزول. |
| المصادر | `python3 scripts/check-sources.py` | طابقت 43 خانة سجلّ المصدر باللغتين. وثّقت المراجعة بيانات المستودعات العامة ومعرّفات أحدث مراجعة، والاستثناءات الترخيصية مفصلة في السجل. |
| لوحة المعلومات | اختبارات نموذج Node وChromium | ثلاثة اختبارات للنموذج وفحص تفاعل الحاسوب والجوال والاتجاه والسمة ولوحة المفاتيح والبحث وسلوك الجدول. اللقطات ببيانات اصطناعية. |
| المخزون | بناء Angular 20.3.35 وبناء ASP.NET Core .NET 10 وفحوص HTTP وChromium | نجح البناءان. اختُبرت المصادقة والتحقق على API فعلي، واختُبرت دورة الواجهة باستجابات محاكاة. تكامل SQL Server بحالة BLOCKED. |
| الفيديو | فحص 1080p و4K والتقاط Playwright | فُك ترميز عينتين عربية وإنجليزية مدة كل منهما 12.9 ثانية، والتُقطت أربع حالات للمتصفح لكل لغة بدقة 1920×1080. عينة 4K ترقّي أصول 1080p. تشمل العينة العربية ترجمة ومدخلًا اختياريًا للتعليق الصوتي. |
| CI والإصدار | مراجعة صيغة Workflow وصلاحيات القراءة وتثبيت الإجراء على مراجعة محددة | GitHub Actions والإتاحة دون تسجيل دخول والإصدار بحالة BLOCKED حتى التحقق عن بُعد. |

يتحقق المشغّل المحلي من الصيغ والاختبارات المحددة. التحقق من هوية المراجع وتشغيل ماسحات خارجية مستقلة والتحقق من اكتشاف المهارات في العملاء الفعليين إجراءات منفصلة. تقتصر نتائج كل اختبار على بيئته المبيّنة.
