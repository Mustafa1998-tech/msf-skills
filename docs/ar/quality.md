# الجودة والإصدار

[English](../en/quality.md)

سجّل لكل بوابة النطاق والأمر أو الأثر والنتيجة والمراجعة المعنية. يشمل PASS الدليل المذكور فقط. يسجّل FAIL فحصًا نُفّذ وفشل. توضّح BLOCKED الوصول أو أداة التشغيل أو الدليل الناقص. تتطلب NOT APPLICABLE سببًا مرتبطًا بالنطاق.

| البوابة | الدليل |
| --- | --- |
| الاكتشاف | المهمة والحدود وأعراف المستودع واختيار المهارات |
| المعمارية | العقود والقرارات والتوافق والمخاطر |
| التصميم | السمات والاتجاهات ولوحة المفاتيح والأبعاد والمراجعة البصرية |
| الهندسة | فروق التنفيذ والبناء أو فحوص الكود المركّزة |
| الأمن | النطاق المصرّح والنتائج وفحص الأسرار والتراخيص |
| الاختبار | الاختبارات الفعلية ورمز الخروج والبيئة |
| التوثيق | الروابط وتكافؤ اللغة والتحقق من الأوامر |
| الفيديو | فحص الوسائط وفك الترميز والتوقيت واللغة والمراجعة البشرية |
| الإصدار | SHA على GitHub وإتاحة المستودع ونجاح CI والتفويض |

يشغّل أمر الجودة الافتراضي الفحوص المحلية. أضف `--with-video` لفحص تصيير العينة. يتطلب الوضع الصارم أدلة مراجعة إلى جانب الفحوص المحلية. راجع `python3 scripts/run-quality-gates.py --help`. لنتائج Actions واكتشاف العميل والنشر والإصدار أدلتها المنفصلة. راجع نسخة الإصدار المعنية في CI قبل إنشاء الوسم العام واحتفظ بالآثار السابقة للتراجع.
