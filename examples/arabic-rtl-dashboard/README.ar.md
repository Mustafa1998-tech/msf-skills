# مِرْصاد: لوحة متابعة الشحنات

[English](README.md) · [مسار التصميم والتحقق](VISUAL.md)

مرصاد مثال مستقل لفريق متابعة الشحنات. يستخدم بيانات اصطناعية ويبدأ بالعربية واتجاه من اليمين إلى اليسار. يمكن تبديل اللغة والوضع الفاتح أو الداكن مع الاحتفاظ بالبحث والتصفية. لا يتطلب خادماً خلفياً أو حساباً.

شغّل من هذا المجلد `python -m http.server 8080 --bind 127.0.0.1` ثم افتح `http://127.0.0.1:8080`. افتح الشحنات المتأخرة وراجع التفاصيل، أو ابحث برمز `MC-4182` أو باسم المركز أو محتوى الشحنة. تتضمن قائمة المراكز بحثاً باسم المركز أو رمزه، ويمكن تشغيلها وإغلاقها بلوحة المفاتيح. يمكن تمرير الجدول أفقياً على الهاتف.

نفّذ `node --test model.test.mjs` لاختبار البحث والتصفية والإجماليات. يوضّح [الدليل الإنجليزي](README.md#verify) طريقة تشغيل اختبار المتصفح للتحقق من اتجاه النص والسمة والتركيز وحالة عدم وجود نتائج.
