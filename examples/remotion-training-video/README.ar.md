# مثال Remotion للفيديو التدريبي (اختياري)

[English](README.md) · [استوديو فيديو MSF](../../skills/msf-video-studio-ar/SKILL.md)

هذا نموذج **أصلي من MSF** بواجهة وهمية ونتيجة حفظ ظاهرة، ويحتوي على نسختين: عربية من اليمين لليسار وإنجليزية من اليسار لليمين. لا يصوّر نظامًا حقيقيًا ولا يحتوي صوتًا أو ملفات خارجية، ولا ينشر شيئًا. يكمل مسار FFmpeg الحالي ولا يستبدله.

## التجهيز والتشغيل

تحتاج Node.js وnpm، واتصالًا عند تثبيت الحزم الاختيارية أو متطلبات متصفح Remotion. افحص الحزم المثبتة في المثال، و[ترخيص Remotion](https://www.remotion.dev/docs/license/pricing) قبل استخدامه؛ بعض الجهات أو استخدامات الإنتاج الآلي تحتاج ترخيصًا مدفوعًا.

من مجلد المثال:

```sh
cd examples/remotion-training-video
npm install
npm run typecheck
npm run dev
```

لإخراج الفيديوهات من نافذة أوامر ثانية:

```sh
npm run render:ar
npm run render:en
npm run render:ar:4k
npm run render:en:4k
```

الإخراج الأساسي 1920 × 1080 وبمعدل 30 إطارًا/ثانية، واختيار 4K يستعمل `--scale=2` لإخراج 3840 × 2160. يعتمد المشهد على النصوص والعناصر المرسومة، ولا يكبّر لقطات شاشة منخفضة الدقة. يكتب الناتج داخل `out/` محليًا، ولا تُرفع الحزم أو الفيديوهات للمستودع.

## مهارات الوكيل (اختيارية)

بعد مراجعة المشروع، شغّل `npx remotion skills add` داخل مشروع Remotion لتثبيت المهارات الرسمية المدعومة من أدوات الوكلاء. ويمكن مراجعة [سجل مصادر Remotion](../../GITHUB_SOURCES.ar.md) أو أرشيف ملحق Codex المرخّص MIT الموجود في `vendor/`. لا ينتقل ترخيص MSF إلى Remotion أو المهارات الخارجية.

## تخصيص النموذج ومراجعته

استخدم صورًا أو مقاطع مصرحًا بها ومنقحة، أو صمّم واجهة تدريبية وهمية. طابق مواضع المؤشر مع الأزرار، وأظهر الحالة الأولية ونتيجة النجاح. راجع المصطلحات العربية والاتجاه وتشكيل الأحرف وتوقيت الصوت والترجمة إن أضفتها. افحص الإطارات لمنع ظهور أسرار أو بيانات شخصية. نجاح فحص TypeScript لا يثبت نجاح إخراج الفيديو أو اجتياز المراجعة البصرية.

إن لم تحتج تحريكًا برمجيًا باستخدام React فاستمر في [مسار FFmpeg المحلي](../software-training-video/README.ar.md). راجع [دليل ربط Remotion](../../skills/msf-video-studio-ar/references/remotion.md).
